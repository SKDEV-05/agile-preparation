# Educational UX & Active Learning Loop Standard · FullStack 2A

## 1. The 8-Step Pedagogical Loop
Transform passive reading into an active feedback engine:
1. **Discover**: Overview, exam stakes, prerequisites.
2. **Understand**: Official definition + intuitive metaphor ("En clair") + deep analysis.
3. **Practice**: 5 interactive labs (PERT, Gantt, Jira, Git, CI/CD).
4. **Test**: 200 progressive QCMs with keyboard shortcuts and instant feedback.
5. **Identify Weakness**: Automatic logging of wrong questions in "Mes Erreurs".
6. **Review**: 3D Flashcards for active recall and mistake re-testing.
7. **Apply**: EFM practical case studies with official marking schemes.
8. **Progress**: Real-time mastery percentages, celebration moments (canvas confetti), exam readiness scores.

## 2. Reducing Student Cognitive Load
- Chunk complex lessons into bite-sized sequential learning steps.
- Clear answer to: "What am I doing?", "Why am I doing it?", "What should I do next?".
- Keep actionable CTAs prominent.
